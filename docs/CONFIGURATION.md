# Настройки VOT

Полный экран: YouTube → Настройки → VOT · Перевод видео → Настройки VOT.
Быстрый экран из плеера: удержать значок или выбрать VOT в шестерёнке.
В быстром экране только языки, громкость и смещение. Включение/выключение — кнопкой плеера.

## Звук и языки

Оригинал и перевод регулируются независимо. Положительное смещение воспроизводит
озвучку раньше, отрицательное — позже, диапазон ±5 секунд. Поддерживаемая скорость
локального аудиоплеера 0.5–2×; на других скоростях озвучка приостанавливается.
Пауза/перемотка синхронизируются с часами видео. Реклама/Cast/AirPlay могут временно
блокировать перевод. Работа на всех маршрутах ещё не проверена.

## Автоматический перевод

Включить «Автоматически переводить все видео». Запрос начинается после примерно
секунды устойчивого продвижения часов видео, а не сразу по появлению его ID.
Это снижает вмешательство во время первоначальной загрузки и лишние запросы при
быстром перелистывании. Ручная кнопка не требует этого ожидания.

В «Не переводить автоматически с этих языков» отметить исключения, например русский.
Язык берётся из выбранной аудиодорожки, затем автоматических субтитров; явно заданный
язык оригинала служит запасной подсказкой. en-US и en.4 нормализуются в en.
Если язык неизвестен и исключения заданы, после ожидания метаданных автозапуск
пропускается с пояснением. Ручная кнопка обходит исключения. Выключение кнопкой
не включает озвучку снова каждые 200 мс: автоматическое решение принимается один раз на ролик.

## Яндекс и живые голоса

**Стандартный перевод работает без входа.** Вход нужен для запроса живых голосов
напрямую через API Яндекса. Кнопка обновления ↻, строка обновления и жест вниз
повторно проверяют профиль. Временная ошибка сети не стирает сохранённый вход.

Вход: «Войти через Яндекс» → войти на странице Яндекса → скопировать показанный код
→ закрыть браузер → «Ввести код подтверждения» → вставить код. Применяются OAuth +
PKCE; токен хранится в Keychain. Пароль вводится на сайте Яндекса. При недоступном
Keychain выбранная подпись может не позволить сохранить вход. «Выйти из VOT» удаляет
токен только этого патча. Не прикладывайте код/токен к issue или логу вручную.

## Свой Worker и проксирование

«Серверы и проксирование»: сначала ввести HTTPS-адрес своего VOT Worker, затем
выбрать режим. Допускается домен без схемы — добавляется HTTPS. Логин, query и
fragment в базовом адресе не поддерживаются.

| Режим | API перевода | Готовое аудио Яндекса |
|---|---|---|
| Напрямую | API Яндекса / свой совместимый API | Исходный URL |
| API через Worker | Worker | Исходный URL |
| API + озвучка через Worker | Worker | `/video-translation/audio-proxy/` у Worker |

Современный Worker использует бинарное тело и `X-VOT-Headers` с base64 JSON заголовков.
Legacy переключается отдельно: JSON `{headers, body}`; payload ограничен 8 МБ для
снижения памяти. Современный вариант предпочтителен для больших исходных аудио.
Не все серверы реализуют оба протокола и endpoint аудио-прокси.

Адрес `vot-worker.eu.cc` дал успешные ответы API и готовые дорожки в пользовательском
логе 0.3.1. Доступность сервера может изменяться; это не гарантированный сервис проекта.
В режиме API + аудио переписывается известный Yandex-префикс `/tts/prod/`;
неизвестные адреса не подменяются предположениями.

Медиа-прокси исходного аудио — отдельное необязательное поле:
`/v1/proxy/video.mp4?format=base64&force=true&url=…`. Если задан, используется независимо
от режима Worker, но только при доступном URL исходного аудио. Он не решает сам по
себе отсутствие такого URL/SABR. Видеопоток YouTube и системный VPN не меняются.

Ссылки/аудио передаются выбранным серверам. OAuth передаётся только напрямую
`api.browser.yandex.ru`; через Worker/сторонний API используется стандартный голос.
Сохранённое предпочтение живых голосов применяется при возврате к прямому Яндексу.

## Кеш и обслуживание

Кеш полных дорожек — до 128 МБ. Автоочистка включена: 24 часа от сохранения,
просмотр не продлевает срок. Проверки при запуске/возврате, каждую минуту работающего
процесса и при операциях кеша. Текущий файл защищён до остановки. Если iOS приостановила
приложение, удаление выполняется при следующем запуске/возврате.

«Очистить кеш» останавливает озвучку, удаляет скачанные дорожки, сохраняет вход и
настройки. «Сбросить все настройки» также восстанавливает значения по умолчанию и
удаляет токен Яндекса, с подтверждением в приложении. Логи остаются отдельно.

«Диагностика и запись лога» содержит копирование диагностики и начало/остановку/
экспорт записи. [Инструкция](LOGGING.md).
