# Управление VOT 0.2.x-alpha

## Установка через GBox

Импортировать исходную рабочую IPA YouTube 21.40.5. Удалить из списка внедрения
старые DNYouTubeVOT и DNYouTubeVOTProbe. Внедрить только новую
`DNYouTubeVOT.dylib`, переподписать приложение и вложенный код. Probe теперь
не нужен: его загрузку пользователь уже подтвердил. Готовая IPA 0.1.0 не нужна.

## Настройки приложения

Открыть настройки YouTube. Добавляется отдельная категория **VOT · Перевод видео**:
- **Озвучка и громкость**: языки, уровни оригинала/перевода, смещение, автоперевод.
- **Аккаунт Яндекса**: вход, ручной ввод токена, выход, переключатель живых голосов.
- **Сервер перевода**: Яндекс напрямую или собственный HTTPS-совместимый сервер;
  транспорт «Прямой API» или современный «VOT Worker» (X-VOT-Headers).

Если имеется совместимый мод группировки, категория попадает в его «Tweaks».
Без него используется собственный список YouTube. Зависимости от наличия мода
нет. Перехваты сверены статически с 21.40.5; размещение на устройстве требует
проверки. Плавающей кнопки с версией в основной библиотеке больше нет.

## Плеер

Значок **waveform.bubble** добавляется в штатный верхний ряд controls:
- нажатие выключенного значка запускает запрос;
- на значке идёт таймер прошедшего ожидания `м:с`, видео можно смотреть дальше;
- когда AVPlayerItem готов, значок становится зелёным, а перевод включается
  автоматически с текущей позиции видео;
- нажатие во время ожидания отменяет запрос; нажатие активного значка отключает
  перевод и восстанавливает оригинальный звук;
- смена видео отменяет прежнюю работу; автоперевод следующих видео опционален;
- долгое нажатие открывает параметры звука/языков/смещения.

В нативное меню шестерёнки добавляется **VOT · Озвучка и громкость** через
адаптеры YTActionSheetController и overflowMenuView. YouTube может использовать
другой тип меню: если пункт не появился, удержание значка остаётся доступным.
В диагностике есть счётчик `Player menus decorated` для проверки адаптера.

Кнопки принадлежат controls плеера и скрываются с ними. Постоянной кнопки
поверх главной ленты нет.

## Вход и живые голоса

1. VOT → Аккаунт Яндекса → Войти через Яндекс.
2. На странице Яндекса войти, подтвердить разрешение и скопировать показанный код.
3. Закрыть окно браузера → Ввести код подтверждения → вставить код.
4. После подтверждения профиля включить «Живые голоса» при желании.

Используется публичный OAuth client_id upstream VOT, схема authorization_code +
PKCE S256 с криптографическим случайным verifier; сервер пользователя для входа
не нужен. Код живёт в памяти до 10 минут. Пароль вводится на странице Яндекса,
не в поля VOT. Альтернатива — ввод собственного OAuth-токена внутри приложения.
Не присылать токен в issue/чат/диагностику.

Токен проверяется только через login.yandex.ru и хранится в Keychain
AfterFirstUnlockThisDeviceOnly, без записи в UserDefaults/логи. Если Keychain
не разрешён выбранной подписью, вход покажет ошибку вместо небезопасного хранения.
Кнопка «Выйти из VOT» удаляет локальный токен, не разлогинивает остальные приложения.

OAuth отправляется только в translate-запрос живых голосов напрямую
https://api.browser.yandex.ru; редиректы API и auth-запросов не выполняются.
Через сторонний сервер живые голоса в этой версии блокируются до переключения
на Яндекс напрямую. Стандартный режим не требует токена.

## Проверено и не проверено

- Пройдены компиляция с -Werror, подписи/секции Mach-O, host-тесты состояний
  ожидания/готовности/отключения, тесты protobuf и независимая byte parity,
  включая field 18 живых голосов.
- Прямой контрольный MP4 через Яндекс дал URL перевода и 1024 байта MP3 (HTTP 206).
- Для пользовательского xvFZjo5PgG0 запрос принят HTTP 200, получен status 6
  (нужно исходное аудио). Полный перевод не проверен.
- Публичные worker-адреса из upstream-конфигураций в проверке не прошли сессию:
  vot-worker.eu.cc вернул HTTP 405, vot-worker.toil.cc — HTTP 503. Поэтому они
  не предлагаются как готовые рабочие presets; можно указать свой совместимый адрес.
- Вход в реальный аккаунт, Keychain, живые голоса, новые controls и меню на iPhone
  разработчиком не проверены. Компиляция не подтверждает эти сценарии.

После установки прислать диагностику после попытки перевода. Поля Source URL,
Source failure и Network trace помогают отличить отсутствие исходника, сбой
upload и ошибку сервиса. Диагностика не содержит токена или подписанного медиа-URL.


## Проверка кнопки в 0.2.1

Внедрить только новую DNYouTubeVOT.dylib вместо предыдущей, без Probe.
Открыть обычное видео и коснуться области видео, чтобы показать верхние controls.
Ожидается значок waveform слева от остальных верхних кнопок. Он скрывается
вместе со штатными controls. Проверить также полноэкранный режим.

Если значок не появился, прислать скриншот с видимой шестерёнкой и полную
диагностику 0.2.1: особенно Player layout passes и строки Button 1.
При открытии панели controls могут скрыться, поэтому alpha в момент копирования
не доказывает, что кнопка была невидима до открытия панели.
