# Совместимость плеера

Собственный адаптер перевода должен работать независимо от других модов.
Наличие мода не считается доказанным конфликтом: проверять нужно одинаковую IPA,
настройки, видео и действия с включённой/выключенной DNVOT.

## Границы интеграции

| Область | Возможное изменение в приложении | Поведение DNVOT |
|---|---|---|
| PiP и фон | Отдельный контроллер PiP, другой backend видео, смена видимости окна | Синхронизация по content media time, без принудительной замены видео-backend |
| Предпросмотр ленты | Несколько экземпляров player controller рядом с watch/мини-плеером | Контексты InlineMutedPlayback исключены из выбора |
| Shorts/Reels | Другой плеер и жизненный цикл | Исключены; поддержка перевода Shorts не заявлена |
| Геометрия видео | Safe area, zoom, engagement panel, fullscreen | DNVOT не меняет constraints rendering view |
| Кнопки controls | Скрытые overflow/CC/Cast, разный порядок и контейнер | Сигнал верхнего ряда управляет видимостью; скрытие всего overlay имеет приоритет |
| Конфигурация A/B | Другой UI, изменённые приватные методы | Проверка наличия и ABI сигнатур, пропуск неподходящего hook |
| Качество/декодеры | Другие VP9/AV1/HLS потоки и ABR | Качество видео не меняется; полный локальный файл озвучки декодируется отдельно |
| Открытие внешней ссылки | Новый watch/deep link в существующем приложении | Новое видео проходит обычную проверку ID/языка/устойчивого запуска |

До первого события видимости верхнего ряда выбирается видимый соседний control.
Если ни один подходящий метод в конкретной версии YouTube не доступен, это
не означает полную совместимость: нужна проверка устройства и диагностический лог.

## 0.4.1-test.1

Устранены два риска в собственном адаптере:

1. `observePlayer:` принимал любой видимый YTPlayerViewController. Теперь
   проверяется класс overlay, сам player и его UIKit-родители, включая суперклассы.
   Превью/Shorts не могут заменить основной watch-плеер. Если выбранный объект
   впоследствии перешёл в такой контекст, перевод останавливается с восстановлением
   громкости и привязка снимается.
2. Кнопка VOT копировала hidden/alpha первой найденной кнопки overflow.
   Теперь её состояние определяется верхним рядом controls; отменённое autonav
   и скрытый overlay скрывают кнопку. До первого сигнала используется видимый сосед.

Добавлены host-тесты фильтра классов и порядка show/hide/cancel событий.
Проверка цепочки UIKit на реальном iPhone остаётся обязательной. Это изменение
не устанавливает причину ранее замеченной перезагрузки watch-страницы.
