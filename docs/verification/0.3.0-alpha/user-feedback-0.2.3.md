# Анализ записи 0.2.3-alpha

Пользователь подтвердил слышимый перевод, работу PiP и фона. YouTube 21.40.5,
iOS 27.0.1. JSONL успешно записан, остановлен и экспортирован на устройстве.
Сводка/хеш исходного файла: [log-summary.json](log-summary.json). Сам журнал
просмотра не включён в репозиторий; ниже только технические результаты.

98.03 с, 579 событий, 494 sample; 316 sample с играющим аудио, из них 52 —
в UIApplicationStateBackground. Все три play успешны: запуск, продолжение после
паузы, второй запуск. Два prepare успешны, HTTP session/translate/download 200,
нет сетевых/decode ошибок. Два скачивания одинакового файла 9 815 853 байта
примерно по 2.12/2.15 с. Файл 613.464 с, mono 24 kHz. Две начальные перемотки,
циклических seek нет. Системная громкость 0.3, выход Speaker, Playback session.

Измеренное contentTime − audioTime: min 0.0266, median 0.0686, max 0.1662 с.
Это разница опрошенных часов, не аппаратное измерение слышимой синхронизации.
Пауза/продолжение отработали. После выключения оригинал возвращается к 1.0;
понижение originalLevel вплоть до 0 соответствует изменениям ползунка в записи.
Аудиометры показывают декодируемый сигнал, максимум peak около −0.49 dBFS;
паузы с уровнем тишины не являются ошибкой. Больших пропусков sample нет
(максимум 0.374 с). PiP отдельно подтверждён пользователем: отдельного PiP-поля
в журнале нет. Фоновая проверка короткая; длительный фон/Bluetooth не проверены.

## Служебные дефекты

- Перед появлением ID видео повторяется translation_stop: nil isEqualToString:nil
  возвращает NO, tick считал отсутствие видео сменой. Это не потеря активного звука.
- После отключения могли остаться moving YES и gate video pause callback при
  enabled NO; итоговый снимок был уже после выключения и не описывал прошлый звук.
- Второй запуск повторно скачивал файл; добавлен ограниченный дисковый кеш.

В 0.3.0 исправлены сравнение пустых ID, запись stop только при реальной работе,
сброс движущихся часов/паузы и disabled gate. Серьёзных скрытых сбоев в этой записи
не обнаружено. Это не проверка всех роликов, длительностей, серверов и устройств.
