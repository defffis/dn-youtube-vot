# Проверка 0.4.1-test.1 — 26.10.2026

Собрана ARM64 dylib для iOS 16+ в Linux Clang/LLD 18.1.3. Сборка -Werror/fatal warnings, Mach-O зависимости/constructor/ad-hoc page hashes проверены. UBSan core tests, protobuf parity и проверка дерева/Markdown-ссылок прошли.

Новые регрессии: исключение InlineMutedPlayback/Shorts/Reels, разрешение обычного watch и mini-контекста, скрытый необязательный сосед при видимом ряде, скрытие controls при ещё видимом соседе, отменённый autonav и приоритет скрытия всего overlay.

Старые тесты синхронизации, автостарта, TTL кеша, языков и маршрутов сохранены. Зависимости по-прежнему только системные; сторонние патчи не загружаются библиотекой.

На iPhone эта сборка не запускалась разработчиком. Совместимость всей комбинации модов не подтверждена; устранение прежней перезагрузки watch-страницы не заявляется.

Порядок ручной проверки: [DEVICE_TEST](../../DEVICE_TEST.md), [совместимость](../../COMPATIBILITY.md). Опубликованный Latest остаётся 0.4.0.
