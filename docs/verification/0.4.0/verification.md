# Проверка 0.4.0

Сборка Linux Clang 18.1.3 / ld64.lld, ARM64 iOS16+, -Werror/fatal warnings.
Проверены UUID/constructor/зависимости и ad-hoc page hashes. UBSan C++ и Google
Protobuf parity прошли. Отдельный тест исходного дерева/Markdown-ссылок пройден.

Новый AutoStartGate тестируется на первом неподвижном кадре, частичном движении
до остановки, возобновлении, быстром переключении ID, скачке seek и невалидных
часах. Не требуется подставлять значение приватного playerState как истину:
учитывается реальное непрерывное продвижение media time. Изменения оформления
проверены компиляцией; UIKit/новые hooks на iPhone ещё не исполнялись разработчиком.

По пользовательскому логу 0.3.1: 104.03 с, 530 samples, 4 успешных prepare/play,
2 cache hit, 2 успешные загрузки, API Worker HTTP 200. Для одного перевода status
6 → server fallback → status 2 означает ожидание, а не готовую дорожку/ошибку.
Переходы обратно в загрузку видны как при раннем auto request, так и при исключённом
ru без созданного audio. Это не устанавливает виновника перезагрузки watch-страницы.
Сырые логи/ID просмотров не включены в публичную документацию. Подробный порядок
сравнения: [TROUBLESHOOTING](../../TROUBLESHOOTING.md).

## Аудит подготовки к открытию

Снимок исходного main (115 файлов) проверен шаблонами OAuth/GitHub token/private key/
подписанных URL, затем просмотрены совпадения. Единственное совпадение — фиктивный
`sig=XYZ` в тесте маршрута. Пользовательских токенов/ключей/IPA/SDK в текущем дереве
не обнаружено. Исторические отчёты и release manifests удалены из текущего дерева
обычным коммитом; история коммитов не переписана. Исходные MIT-уведомления сохранены.
Старые GitHub release assets и видимость репозитория управляются отдельно от Git.

Сохранённый хеш последнего пользовательского JSONL — только для сопоставления
дубликата; сами JSONL и ссылки на просмотренные видео в репозиторий не добавлены.
