# Отчёт пользователя о 0.2.1

YouTube 21.40.5 / iOS 27.0.1. Пользователь подтвердил появление кнопки
(скриншот со значком waveform), но не слышит перевод, оригинал не приглушается.
Сервис вернул готовую дорожку, загрузка повторно из кеша сеанса.

Enabled YES, content 289.191, audio 289.028, audio item status 1 (ready),
audio rate 0, timeControlStatus 0 (paused), waiting reason отсутствует.
User paused NO, seeking NO, advance age 0.161. Из старого лога неизвестны
attemptingToPlay, длительность аудио и все блокирующие флаги.

Зелёный значок в 0.2.1 означал readyToPlay, а не реальное воспроизведение —
это подтверждённый дефект индикации. В коде также существовал veto по приватному
attemptingToPlay, даже при продвижении content clock. Причина конкретной паузы
на устройстве не доказана этим логом; 0.2.2 убирает этот veto и добавляет gate.
