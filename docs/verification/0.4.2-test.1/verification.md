# Проверка 0.4.2-test.1 — 27.10.2026

ARM64 iOS 16+ dylib собрана в Linux Clang/LLD 18.1.3 с -Werror/fatal warnings. Проверены constructor, UUID, системные зависимости (включая QuartzCore) и ad-hoc page hashes.

Пройдены UBSan core tests, request protobuf parity и независимые Google Protobuf fixtures optional int32 ETA: отсутствие, ноль, положительные значения, -1, INT32_MIN и INT32_MAX. Непригодное значение не подменяется интервалом опроса.

Проверены фазы подготовки/скачивания, неизвестный размер, отрицательные счётчики, ограничение кольца до реальной готовности, отключение/кеш/новый запрос; размеры native control, невалидная геометрия и смещение центра glyph. Регрессии синхронизации, автостарта, превью, языков и кеша сохранены.

По фотографиям пользователя замечены залитый значок, большой промежуток перед autoplay и небольшое вертикальное смещение. Код заменён контурной геометрией, spinner/байтовым кольцом и вставкой рядом с обычными native controls. Это анализ изображения и проверка кода, а не runtime-подтверждение нового UI. Фотографии в исходники не включены.

На iPhone новая версия не запускалась разработчиком: реальные интервалы/вертикальное выравнивание, касание, скрытие/появление, Reduce Motion, VoiceOver и фон требуют проверки. Причина прежней перезагрузки watch не считается установленной.
