# Архитектура

Нативная ARM64 dylib с системными Foundation/UIKit/AVFoundation/Security.
Bootstrap ждёт активное окно и ищет YTPlayerViewController. Runtime-адаптер проверяет
сигнатуры перед перехватом и сохраняет исходные реализации. Substrate и другие моды
не требуются. Работа с данными другого приложения ограничена собственным контейнером
приложения, в которое внедрена библиотека.

NativeUI добавляет категорию настроек и UIButton 44×44 в верхний ряд controls.
Hooks наблюдают активацию/паузы/громкость/reload; DNVOT не вызывает reload YouTube.
Controller связывает ID/часы видео с собственным AVAudioPlayer. Автостарт требует
секунду непрерывного движения видео, ручной запуск обходит это ожидание.
Сервис сначала возвращает URL перевода; полный HTTPS-файл сохраняется локально,
декодируется и синхронизируется паузой/seek/малой коррекцией скорости.

Client формирует protobuf, подписи и сессию VOT, опрашивает результат и обрабатывает
запрос исходного аудио. При доступном native googlevideo URL загружает до 32 МБ;
иначе запрашивает серверное получение. Поддержка всех форматов/SABR не гарантируется.
Modern/legacy Worker используют разные envelopes. OAuth пользователя отправляется
только официальному прямому API Яндекса, не Worker.

Кеш полных файлов ограничен 128 МБ, TTL 24ч от сохранения, активный файл защищён.
Recorder пишет JSONL через отдельную очередь с выбранными полями, без headers/URL/
OAuth/audio. Исследование основано на проектах, перечисленных в [NOTICE](../NOTICE.md).
Приложение YouTube, Apple SDK и чужие моды не включены в исходники/релизы.
