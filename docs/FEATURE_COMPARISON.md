# Сравнение и предложения

Исходная работа: [ilyhalight/voice-over-translation](https://github.com/ilyhalight/voice-over-translation),
[возможности в README](https://github.com/ilyhalight/voice-over-translation#возможности).
Это источник идей, протокола и схем прокси; DN YouTube VOT — отдельная нативная
реализация для приложения YouTube iOS, не браузерное расширение.

| Возможность исходного расширения | DN YouTube VOT 0.3 |
|---|---|
| Озвучка видео, раздельная громкость | Реализовано; звук 0.2.3 подтверждён пользователем |
| Автоперевод и исключения языков | Реализовано в 0.3; новая проверка на устройстве нужна |
| Worker и режимы проксирования | Реализованы основные маршруты, modern/legacy; свой endpoint нужно проверить |
| Адаптивное приглушение во время речи | Пока фиксированный уровень оригинала на время playing |
| Переводные субтитры и оформление | Пока отсутствуют |
| Сохранение субтитров SRT/VTT/ASS/JSON | Пока отсутствует |
| Сохранение озвучки MP3 | Есть внутренний кеш, пользовательского экспорта MP3 пока нет |
| Перевод отдельных слов в субтитрах | Пока отсутствует |
| Разные сайты | Патч ориентирован на обычные видео YouTube iOS |

## Предлагаемый следующий порядок

1. Адаптивное приглушение: возвращать оригинал между фразами с плавными переходами,
   порогом тишины и задержкой, чтобы громкость не дёргалась. Сохранить фиксированный
   режим как выбор пользователя. Метры текущего backend уже дают сигнал для проверки.
2. Прогресс загрузки в процентах/МБ и повтор неудачной операции без повторного входа.
   Показывать причину пропуска автоперевода и найденный язык в статусе.
3. Экспорт готовой озвучки из локального кеша через «Файлы», с названием/языками ролика.
4. Переводные субтитры и экспорт SRT/VTT, затем оформление и перевод отдельных слов.
5. Устойчивое извлечение исходного аудио/SABR для роликов, которым VOT возвращает
   запрос upload; успешное воспроизведение готовой дорожки этот сценарий не закрывает.
6. Длительные прогоны PiP/фон, Bluetooth/звонки/перемотка/другие скорости; совместимость
   с чистой IPA и другими версиями YouTube. Скорости вне 0.5–2× требуют иного backend.

Предложения не объявляются выполненными. Не стоит возвращать потоковый AVPlayer
без воспроизведения прежней проблемы и измерения поведения: локальный backend
впервые дал подтверждённый слышимый звук.
