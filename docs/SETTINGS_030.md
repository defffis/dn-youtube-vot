# DN YouTube VOT 0.3.x-alpha (текущая 0.3.1)

## Установка

В GBox заменить DNYouTubeVOT.dylib предыдущей версии новой, без Probe и второй
копии библиотеки. Переподписать приложение и вложенный код. IPA не требуется.
Настройки 0.2.x сохраняются; прежний Worker переносится в отдельный адрес Worker.

## Основные настройки и плеер

YouTube → Настройки → VOT · Перевод видео → Настройки VOT:

- Озвучка: языки, уровни оригинала/перевода, смещение.
- Автоматический перевод всех обычных видео и выбор языковых исключений.
- Подключение: аккаунт Яндекса, серверы и проксирование.
- Обслуживание: диагностика/запись лога, очистка кеша, сброс всех настроек.
- О проекте: GitHub defffis, репозиторий патча, исходное расширение ilyhalight.

Текстовых кнопок включения/выключения перевода в настройках нет. Использовать
значок в плеере. Его удержание или пункт VOT в шестерёнке открывают только быстрые
настройки звука/языков/смещения. Ссылок на аккаунт/серверы и инструментов логирования
в быстрых настройках нет. Значок скрывается вместе со штатными controls.

## Автоперевод и исключения

Переключатель применяется к текущему и следующим обычным видео. Сначала используется
язык выбранной аудиодорожки, затем язык автоматических субтитров YouTube. Если
метаданных нет, явный исходный язык из настроек может служить подсказкой.
Для исключений используется базовый код: en-US → en, ru.4 → ru.

Отмеченные языки пропускаются только автоматически. Ручная кнопка обходит
исключения. Если исключения не заданы, неизвестный язык переводится с автоопределением.
Если исключения заданы и язык не найден за 5 с, автозапуск пропускается с понятным
статусом; ручной запуск доступен. Один ролик обрабатывается автоматически один раз,
чтобы нажатое пользователем выключение не включалось обратно каждый tick.
Выключение автоматического режима останавливает перевод, запущенный автоматически;
перевод, включённый вручную, остаётся управляемым кнопкой плеера.

Источники языка — внутренние интерфейсы YouTube 21.40.5, новые runtime-пути требуют
проверки на устройстве. Исключения не обещают акустическое распознавание языка.

## Серверы и прокси

Три режима, соответствующие смыслу режимов исходного расширения:

| Режим | API VOT | Готовая озвучка Яндекса |
|---|---|---|
| Напрямую | API Яндекса / свой совместимый API | По исходному URL |
| API через Worker | Свой Worker | По исходному URL |
| API + озвучка через Worker | Свой Worker | Worker /video-translation/audio-proxy/ |

Адреса задаются отдельно: API, собственный VOT Worker, необязательный медиа-прокси
исходного аудио. Принимаются HTTPS или домен без схемы; логин/query/fragment
в базовом адресе запрещены. Сначала указать Worker, затем выбрать режим.
Никакой публичный Worker не предлагается как заведомо рабочий.

Современный Worker: бинарное тело + base64 JSON заголовков в X-VOT-Headers.
Legacy: JSON {headers, body}; для бинарного payload body — массив байтов,
для JSON-запроса — объект. Для ограничения памяти legacy payload не более 8 МБ;
современный вариант предпочтительнее для передачи исходного аудио.

Полное проксирование озвучки переписывает только известный префикс
https://vtrans.s3-private.mds.yandex.net/tts/prod/ в совместимый endpoint Worker,
сохраняя остаток пути и query. Другие URL не переписываются предположениями.
Медиа-прокси при заполненном адресе используется независимо от режима Worker
для получения исходного аудио: /v1/proxy/video.mp4?format=base64&force=true&url=… .
При отсутствии доступного URL исходного аудио он не заменяет его извлечение.

Это проксирование запросов VOT, не VPN и не изменение видеопотока YouTube.
Ссылки/аудио передаются выбранным серверам. OAuth передаётся только напрямую
api.browser.yandex.ru. Через Worker/сторонний API автоматически выбирается
стандартная озвучка без входа; сохранённое предпочтение живых голосов применяется
при возвращении к прямому API Яндекса.

## Аккаунт и обслуживание

Стандартный перевод работает без авторизации. Вход нужен для живых голосов
напрямую через Яндекс. Кнопка ↻, строка «Обновить состояние аккаунта» и pull-to-refresh
повторно проверяют профиль напрямую, не останавливая воспроизведение и не стирая
вход при временном сетевом сбое. Успешный вход немедленно обновляет экран.

Кеш содержит полные готовые файлы, до 128 МБ суммарно, с удалением наименее недавно
использованных. В 0.3.1 автоматическая очистка включена по умолчанию: файл
устаревает через 24 часа от сохранения, чтение срок не продлевает. Полная проверка
кеша идёт при запуске, возврате в приложение и каждую минуту, пока процесс
выполняется. Если приложение приостановлено/закрыто — при следующем запуске.
Текущая озвучка защищена до остановки, затем просроченный файл удаляется.
Ключ включает ролик/языки/режим сервера/голоса/аккаунта. Кнопка очистки останавливает
перевод и удаляет кеш, сохраняя настройки, вход и логи. Сброс всех настроек отдельно
подтверждается в приложении, восстанавливает значения по умолчанию, очищает кеш и
вход Яндекса. Логи остаются в отдельном каталоге.

Диагностика: Настройки VOT → Диагностика и запись лога. Там находятся копирование,
начало/остановка записи и экспорт JSONL через «Поделиться». [Подробнее](LOGGING.md).

Сборка, подписи/Mach-O и host-политики проверены. Новые UI, Worker/proxy, кеш,
refresh/reset и определение языка на iPhone разработчиком ещё не проверены.
Звук/PiP/фон/экспорт прежней 0.2.3 подтверждены пользователем и её журналом.
