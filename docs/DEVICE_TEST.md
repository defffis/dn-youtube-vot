# Проверка на устройстве

Для каждого прогона указать версию dylib/YouTube/iOS, установщик, другие моды,
сеть и устройство вывода. Лог содержит ID видео — проверять перед публикацией.

- Прямой API, стандартная озвучка без входа: запуск, ожидание, звук, выключение.
- Громкость оригинала/перевода, восстановление после выключения и ошибки.
- Пауза/продолжение, seek вперёд/назад, 0.5×/1×/2×, конец покрытия файла.
- Автозапуск только после движения видео, исключение ru, ручное включение исключённого видео.
- Быстрое переключение роликов, отмена ожидания, повторное открытие с кешем.
- Кеш: через 24ч не продлевается чтением; активный файл не прерывается очисткой.
- PiP/фон, Bluetooth/проводной выход/динамик, звонки и возврат из прерывания.
- Worker modern/legacy и маршруты API/аудио с собственным совместимым endpoint.
- Вход Яндекса, обновление профиля, доступ Keychain, выход, сброс, очистка кеша.
- Settings/быстрый экран, монохромные состояния, запись/остановка/экспорт JSONL.
- [Сравнение повторных загрузок](TROUBLESHOOTING.md) с выключенным авто и без DNVOT.

Компиляция и host-тесты не заменяют эти проверки. Подтверждённые результаты
и открытые вопросы перечислены в [STATUS](../STATUS.md).

## Регрессии 0.4.1-test.1

- При активном переводе открыть ленту/рекомендации с автопредпросмотром: убедиться,
  что слышимая основная озвучка и ID выбранного watch-плеера не перехватываются превью.
- Повторить с мини-плеером и PiP, затем вернуться в полноэкранный режим.
- Проверить отсутствие автоперевода превью и Shorts.
- Показать/скрыть controls, открыть меню, перейти к следующему видео; кнопка VOT
  должна следовать верхнему ряду, в том числе при скрытом overflow/CC/Cast.
- Проверить с текущими модами и в исходной IPA без них.

## Регрессии 0.4.2-test.1

- Сравнить вертикальный центр и интервалы кнопки VOT со штатными CC/Cast/меню
  в обычном и полном экране. Скрытие CC/Cast не должно убирать VOT.
- OFF/ON/пауза: одна контурная волна, серый/белый цвет, без залитого диска.
- Проверить spinner до ответа/при отсутствии ETA, скачивание с известным/неизвестным размером, кеш и отмену на каждом этапе.
- Проверить, что нулевая/зависшая ETA не включает готовое состояние и не даёт ложный процент.
- Скрыть controls, свернуть приложение, включить Reduce Motion; вращение не должно продолжаться на невидимой кнопке.
- Проверить VoiceOver и зону касания после уменьшения места, занимаемого кнопкой в ряду.
