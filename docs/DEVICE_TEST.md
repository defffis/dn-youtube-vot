# Проверка на устройстве

Для каждого прогона указать версию dylib/YouTube/iOS, установщик, другие моды,
сеть и устройство вывода. Лог содержит ID видео — проверять перед публикацией.

- Прямой API, стандартная озвучка без входа: запуск, ожидание, звук, выключение.
- Громкость оригинала/перевода, восстановление после выключения и ошибки.
- Пауза/продолжение, seek вперёд/назад, 0.5×/1×/2×, конец покрытия файла.
- Автозапуск только после движения видео, исключение ru, ручное включение исключённого видео.
- Быстрое переключение роликов, отмена ожидания, повторное открытие с кешем.
- Кеш: через 24ч не продлевается чтением; активный файл не прерывается очисткой.
- PiP/фон, Bluetooth/проводной выход/динамик, звонки и возврат из прерывания.
- Worker modern/legacy и маршруты API/аудио с собственным совместимым endpoint.
- Вход Яндекса, обновление профиля, доступ Keychain, выход, сброс, очистка кеша.
- Settings/быстрый экран, монохромные состояния, запись/остановка/экспорт JSONL.
- [Сравнение повторных загрузок](TROUBLESHOOTING.md) с выключенным авто и без DNVOT.

Компиляция и host-тесты не заменяют эти проверки. Подтверждённые результаты
и открытые вопросы перечислены в [STATUS](../STATUS.md).
