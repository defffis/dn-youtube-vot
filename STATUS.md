# Статус проекта

Обновлено: 25 октября 2026 года. Версия: **0.3.0-alpha**.

**Пользователь подтвердил слышимый перевод, PiP и фон в 0.2.3.** JSONL показывает
успешное декодирование и устойчивый ход часов; серьёзных скрытых ошибок в этой
98-секундной записи не найдено. Это подтверждение одной установки/ролика.

## Обновление 0.3.0

[Разбор записи](docs/verification/0.3.0-alpha/user-feedback-0.2.3.md) и
[сводка](docs/verification/0.3.0-alpha/log-summary.json). Исправлены повторные idle
stop при пустом ID и устаревший disabled gate. Добавлен ограниченный дисковый кеш.

Собраны: обновлённые общие/быстрые настройки, подменю диагностики, refresh аккаунта,
сброс/очистка, auto/exclusions/unknown-language policy, собственный modern/legacy
Worker, маршруты API/аудио и необязательный source media proxy. GitHub автора и
оригинального расширения есть в интерфейсе и документации.

Host-тесты нормализации языков, исключений/unknown timeout, маршрутов/сохранения
query, пустых ID и прежних sync/protobuf пройдены. ARM64 -Werror/Mach-O/подписи
проверены. **Не проверены на iPhone:** новые меню, динамическое определение языка,
автоперевод/исключения, настоящий пользовательский Worker/прокси, дисковый кеш,
refresh/reset. Для Worker адрес не предоставлялся: контракт реализован, доступность
конкретного сервера не обещается. [Инструкция](docs/SETTINGS_030.md).

## Обновление 0.2.3

Пользователь подтвердил в 0.2.2 снижение оригинала до 0.191, Ducking YES,
успех setter. Но озвучки не слышно; значок мигает. AVPlayer в одном снимке playing,
rate 1, content 324.657 / audio 324.573, play commands 151 при 66 timer passes.
Это не доказывает конкретную причину тишины. [Отчёт](docs/verification/0.2.3-alpha/user-feedback-0.2.2.md).

Заменён backend на AVAudioPlayer из полного локального файла. Убран рекурсивный
remote-seek/play цикл; старт вызывается только для неиграющей дорожки, повтор
не чаще раза в секунду. Добавлен файловый recorder с экспортом JSONL и замерами
аудиосигнала/часов/аудиосессии. Скорость ограничена 0.5–2.0×; файл до 128 МБ.

Пройдены компиляция с -Werror, Mach-O/подписи, protobuf и 400-шаговая host-модель
локальной синхронизации, пауза/реклама/границы скорости/ограничение повторов старта.
**Не проверены на iPhone:** декодирование полученного файла, звук и точность
локального backend, интерфейс/запись/экспорт нового recorder, PiP/фон/маршруты.
[Проверка и инструкция лога](docs/LOGGING.md).

## Полученная обратная связь и текущий блокер

Пользователь сообщил: готовая IPA **0.1.0-alpha вылетает** при установке через
GBox. При отдельном внедрении dylib интерфейс перевода не появился. Модель
устройства, версия iOS, момент падения и полный `.ips` пока не получены.
Это пользовательское наблюдение, а не воспроизведённая разработчиком причина.

В 0.1.0 не было отдельной кнопки в настройках YouTube; это пробел реализации.
В 0.1.1 добавлены постоянный запуск панели **VOT 0.1.1** поверх основного окна,
кнопка VOT в навигации настроек, повторное обнаружение плеера, отложенный bootstrap
без проверки имени executable и отдельная библиотека Probe без движка/хуков.
Убраны перехваты getter currentVideoID и loadView. Добавлен UUID для диагностики.

**Исправление вылета не подтверждено.** 0.1.1 пока имеет только успешную сборку,
проверку обоих Mach-O/конструкторов/подписей и прежние host-тесты. Результаты
первого релиза в таблице ниже относятся к 0.1.0 и сохранены как исторические.
[Порядок проверки GBox](docs/GBOX_DIAGNOSTICS.md).

- [x] Собственная кнопка «Перевод» и нативная панель настроек.

- [x] Получение аудиопотока из нативного плеера, загрузка до 32 МБ и отправка сервису.
- [x] Резервный запрос серверного получения аудио при недоступности потока.
- [x] Пауза, seek, скорость, смещение звука и раздельная громкость.
- [x] Отмена устаревших запросов при смене ролика, обработка ошибок и диагностика.
- [x] Внедрение dylib в отдельную копию исходной IPA с сохранением прежних модов.
- [x] Скрипты сборки, восстановления инструментов, проверки Mach-O и протокола.

Пункты выше означают наличие реализации. Они не означают прохождения проверки

## Что не проверено и остаётся открытым

- [ ] Запуск модифицированной IPA на физическом iPhone.
- [ ] Полная проверка панели/кнопки в обоих режимах (появление значка подтверждено пользователем).
- [ ] Успешный перевод YouTube с реальной отправкой аудио из плеера.
- [ ] Длительный прогон синхронизации (краткий слышимый перевод 0.2.3 подтверждён).
- [ ] Корректное восстановление громкости, реклама и смена видео на устройстве.
- [ ] Совместимость с чистой IPA без сторонних модов.
- [ ] Совместимость с текущим набором модов присланной IPA при запуске.
- [ ] Длительный PiP/фон, Bluetooth, AirPlay/Cast (краткие PiP и фон 0.2.3 подтверждены).
- [ ] Режим «живых голосов» с авторизацией Яндекса — реализация добавлена в 0.2.0, проверка на устройстве не пройдена.
- [ ] Другие версии YouTube и iOS.
- [ ] Запуск сборки через GitHub Actions — отдельно от локальной проверки.

## Порядок продолжения

Сначала пройти [проверку на устройстве](docs/DEVICE_TEST.md), затем устранить
блокеры из [плана](ROADMAP.md). До этого версия остаётся alpha; выпуск стабильной
версии и обещание качественного перевода любых видео преждевременны.
