# Статус 0.4.2

Обычный релиз **0.4.2** основан на 0.4.2-test.1. Пользователь сообщил, что
предрелиз проверен и работает хорошо; предоставлены скриншоты кнопки и настроек.
Это пользовательская проверка, а не полный прогон матрицы устройств разработчиком.
В исполняемом коде изменены только строки версии.
[Поведение кнопки](docs/PLAYER_CONTROLS.md).

Проект остаётся экспериментальным по совместимости, несмотря на обычное оформление
релиза. Адаптер: YouTube 21.40.5, ARM64, iOS 16+. Пользовательские проверки — iOS 27.0.1.

| Сценарий | Подтверждение |
|---|---|
| Звук, приглушение/восстановление оригинала | Пользователь и логи 0.2.3–0.3.1 |
| Краткие PiP и фон | Пользователь 0.2.3; фоновое продвижение аудиочасов в логе |
| Автоперевод en / исключение ru | Логи 0.3.0–0.3.1 |
| Кеш полных файлов и повторное чтение | Два cache hit/prepare в логе 0.3.1 |
| Modern Worker, API через vot-worker.eu.cc | Успешные HTTP 200 и загрузки в пользовательском логе 0.3.1 |
| Вход Яндекса/меню/экспорт лога | Пользовательские проверки предыдущих версий |
| Автостарт/текущая сборка | Host-регрессии; общий положительный отзыв пользователя о 0.4.2-test.1, без отдельного протокола каждого сценария |
| Контурный значок и положение 0.4.2 | Пользовательские скриншоты и положительный отзыв о 0.4.2-test.1 |
| TTL 24ч / активная дорожка | Host-политика; реальное ожидание суток на iPhone не пройдено |
| Причина повторной инициализации видео | Не установлена; [разбор и сравнение](docs/TROUBLESHOOTING.md) |

Сборка Clang -Werror, Mach-O/ad-hoc hashes, UBSan и Google Protobuf parity выполнены
локально. GitHub Actions настроен для ручного запуска, но не выдаётся за пройденный
CI-прогон. [Доказательства текущего релиза](docs/verification/0.4.2/verification.md).

Не подтверждены: чистая IPA без других модов, другие версии YouTube/iOS,
длительные PiP/фон, Bluetooth/звонки/Cast, legacy Worker и проксирование всего аудио,
полный upload для разных вариантов исходного потока/SABR, качество живых голосов.
Готовая IPA не распространяется. [План](ROADMAP.md).
