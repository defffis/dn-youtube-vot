# DN YouTube Voice Translation

Нативный патч для YouTube iOS: закадровый перевод видео через Yandex VOT,
синхронизация озвучки, раздельная громкость, автоперевод и свой VOT Worker.

**Текущий релиз: 0.4.0.** [Скачать](https://github.com/defffis/dn-youtube-vot/releases/latest)
· [Установка](docs/INSTALL.md) · [Настройка](docs/CONFIGURATION.md)
· [Диагностика перезагрузки плеера](docs/TROUBLESHOOTING.md)

В main подготовлена тестовая **0.4.2-test.1**: контурный значок без залитого круга,
индикатор подготовки вместо секундомера и компоновка рядом со штатными иконками.
[Ожидание и индикатор](docs/PLAYER_CONTROLS.md) · [Совместимость](docs/COMPATIBILITY.md).
Новая сборка ещё требует проверки на iPhone; Latest остаётся 0.4.0.

## Возможности

- Кнопка в верхнем ряду плеера, без постоянного оверлея в ленте.
- Контурный белый/серый значок, индикатор подготовки/скачивания, выключение нажатием.
- Языки, громкость оригинала/перевода, смещение, быстрые настройки удержанием значка.
- Автоперевод после устойчивого начала просмотра; исключения исходных языков.
- Яндекс напрямую, свой API или modern/legacy VOT Worker; отдельные маршруты API/аудио.
- Стандартная озвучка без входа; OAuth/PKCE и Keychain для запроса живых голосов напрямую.
- Локальная озвучка, пауза/перемотка/0.5–2×, кеш до 128 МБ с автоочисткой через 24 часа.
- Диагностика, запись событий в JSONL и экспорт через системное меню «Поделиться».

## Совместимость и статус

Адаптер рассчитан на YouTube **21.40.5**, ARM64, iOS 16+. Звук, краткие PiP/фон,
автоперевод, языковые исключения, кеш и современный Worker подтверждены
пользовательскими проверками на iOS **27.0.1**. Это не матрица всех устройств.
Новый стартовый фильтр и оформление 0.4.0 собраны и проверены на host;
проверка на iPhone и сравнение перезагрузок с приложением без патча ещё нужны.
[Что проверено](STATUS.md) · [План](ROADMAP.md).

Озвучка включается после подготовки и полного скачивания файла. На больших
роликах ожидание может быть длительным. Live/Shorts, скорости вне 0.5–2×,
длительный фон, все виды исходных аудиопотоков и сторонние моды не обещаются.

## Быстрый старт

1. Скачать `DNYouTubeVOT.dylib` из актуального релиза.
2. В GBox взять свою рабочую IPA, заменить прежнюю DNVOT новой библиотекой,
   переподписать приложение и вложенный код. Probe и вторая копия DNVOT не нужны.
3. YouTube → Настройки → VOT · Перевод видео → Настройки VOT.
4. Для первой проверки оставить прямой API и стандартную озвучку без входа.
5. Открыть обычное разговорное видео и нажать значок перевода.

[Полная инструкция](docs/INSTALL.md) описывает обновление, настройку Worker,
автоперевод, экспорт лога и проверку конфликтов.

## Сборка в Linux

```bash
python3 -m pip install protobuf==6.33.0
python3 tools/setup_toolchain.py
bash build.sh
bash test.sh
```

Ubuntu 24.04 x86_64; нужны Python, g++, dpkg-deb, tar/xz и доступ к источникам
из [toolchain-lock.json](tools/toolchain-lock.json). Скрипт проверяет фиксированные
хеши LLVM/SDK. Mac не требуется. Результат — `build/DNYouTubeVOT.dylib`.
Подпись сборки ad-hoc; установочный инструмент должен переподписать вложенный код.
Ручной workflow находится в [.github/workflows/build.yml](.github/workflows/build.yml).
SDK, IPA, сертификаты и сторонние моды в релиз проекта не входят.
