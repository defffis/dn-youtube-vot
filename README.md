# DN YouTube Voice Translation

Текущая версия: **0.3.1-alpha**. Автоочистка кеша включена: через 24 часа
от сохранения, без продления при чтении; при старте/возврате/каждую минуту работы.
Исправлена диагностика отменённых загрузок и счётчики предыдущего ролика.
[Анализ 0.3.0](docs/verification/0.3.1-alpha/user-feedback-0.3.0.md). Пользователь подтвердил слышимый перевод,
PiP, фон и экспорт лога в **0.2.3** на YouTube 21.40.5 / iOS 27.0.1.
[Анализ записи](docs/verification/0.3.0-alpha/user-feedback-0.2.3.md).

В 0.3 добавлены собственный Worker (modern/legacy), режимы проксирования,
автоперевод с языковыми исключениями, отдельное подменю диагностики, обновление
аккаунта, очистка кеша и сброс. Быстрые настройки плеера содержат звук/языки/
смещение. Управление включением — только кнопкой плеера, без текстовых дублей.
[Инструкция 0.3](docs/SETTINGS_030.md) · [Сравнение и предложения](docs/FEATURE_COMPARISON.md).
Новые функции 0.3 собраны и проверены на host; runtime-проверка ещё нужна.

Разработано на основе исследования протокола и решений оригинального расширения
**[ilyhalight/voice-over-translation](https://github.com/ilyhalight/voice-over-translation)**
и vot.js. Это отдельный нативный патч. Исходные MIT-уведомления сохранены в docs.
Автор патча: [defffis](https://github.com/defffis).

[Статус](STATUS.md) · [Установка и управление](docs/SETTINGS_030.md) · [Задачи](ROADMAP.md) · [Релизы](https://github.com/defffis/dn-youtube-vot/releases)

Независимая ARM64-библиотека для YouTube iOS, iOS 16.0+, адаптер YouTube 21.40.5.
Собирается в Linux без Mac. Приложение, Apple SDK и чужие моды не включены в Git.

## В этой версии

- Категория **VOT · Перевод видео** в настройках YouTube, с совместимой группировкой.
- Значок в штатном верхнем ряду плеера: старт → таймер ожидания → готовая озвучка
  включается сама и значок зеленеет → повторное нажатие выключает перевод.
- Быстрые настройки плеера: громкость/языки/смещение. Общие настройки: автоперевод, исключения, серверы и обслуживание.
- В плеере: меню шестерёнки VOT и удержание значка для настроек.
- Плавающая кнопка с версией убрана из основной библиотеки.
- Вход в Яндекс по коду (OAuth + PKCE) или токену, хранение в Keychain, выход,
  запрос живых голосов. Вход подтверждён пользователем в 0.2.0; качество живого голоса не подтверждено.
- Сервер: Яндекс напрямую или свой совместимый HTTPS API / современный VOT Worker.
- Подробный лог в подменю диагностики: запуск/остановка, запись во время просмотра, экспорт JSONL.
- Локальная озвучка после полного скачивания (до 128 МБ); скорость 0.5–2.0×.
- Расширенная диагностика исходного аудио/upload/ответов без OAuth и медиа-URL.

## Фактическая проверка

Пользователь подтвердил загрузку **0.1.1** в GBox на iOS 27.0.1/YouTube 21.40.5:
Probe открыл окно, основной патч нашёл плеер. Перевод завершился ошибкой Яндекса.
В **0.2.0** пройдены сборка с -Werror, Mach-O/подписи/конструкторы, host-тесты и
независимое сравнение protobuf, включая живые голоса. Нативные точки интеграции
найдены в бинарнике YouTube. Контрольный прямой MP4 дал доступный MP3.

**Вход подтверждён в 0.2.0, кнопка — в 0.2.1, приглушение — в 0.2.2, слышимый перевод/PiP/фон/лог — в 0.2.3.**
Для пользовательского ролика сервис запросил исходное аудио (status 6).
Публичные worker-адреса в проверке вернули 405/503, рабочий worker не обещается.

## Установка

В GBox взять исходную рабочую IPA, удалить из внедрения прежнюю DNYouTubeVOT и
Probe, добавить только новую DNYouTubeVOT.dylib и подписать приложение/вложенный
код. Готовую IPA 0.1.0 не использовать как проверенную: для неё есть отчёт о вылете.
Подробно: [docs/SETTINGS_030.md](docs/SETTINGS_030.md).

## Сборка и проверки

```bash
python3 tools/setup_toolchain.py
bash build.sh
bash test.sh
```

Результат — build/DNYouTubeVOT.dylib. SDK/LLVM фиксированы в
[tools/toolchain-lock.json](tools/toolchain-lock.json). GitHub Actions запускается
вручную. CI-прогон отдельно ещё не подтверждён. Скрипт patch_ipa.py добавляет
библиотеку в копию расшифрованной ARM64 IPA; подпись и установка выполняются отдельно.

## Структура

- src/NativeUI.mm — собственная интеграция settings/topControls/player menu.
- src/Preferences.mm — серверы, OAuth/PKCE, проверка профиля, Keychain.
- src/DNVOTController.mm — управление, озвучка, панель и синхронизация.
- src/DNVOTClient.mm, VOTWire.hpp — протокол VOT, исходное аудио и запросы.
- docs/verification/ — исторические доказательства по версиям.
- docs/ANALYSIS.md, NOTICE.md — исходные исследования и уведомления.

Библиотека не импортирует Substrate, YTLite, YouPiP, YTVideoOverlay или
YouGroupSettings. Совместимость их размещения используется через доступные
runtime-методы, при отсутствии модов остаются интерфейсы самого YouTube.
Ссылка и исходное аудио передаются выбранному серверу. OAuth передаётся только
напрямую Яндексу для живых голосов. Никогда не присылать токены в issue или чат.
