# DN YouTube VOT 0.1.0-alpha

Первый экспериментальный релиз независимого нативного патча перевода YouTube iOS.
ARM64, минимальная iOS 16.0; адаптер статически проверен по YouTube 21.40.5.

## В комплекте

- `DNYouTubeVOT.dylib` — отдельная библиотека с ad-hoc-подписью.
- `YouTube-21.40.5-DNVOT-alpha.ipa` — предоставленная пользователем IPA с добавленным патчем; прежние моды сохранены.
- `DNYouTubeVOT-0.1.0-alpha-source.zip` — исходники, сборка и отчёты первого выпуска.
- `SHA256SUMS.txt` — контрольные суммы загруженных файлов.

IPA необходимо переподписать перед установкой на обычный iPhone.

## Реализовано

Кнопка и панель перевода, выбор языков, стандартная озвучка VOT, передача исходного
аудио, пауза/перемотка/скорость, отдельная громкость и смещение, отмена при смене
ролика и диагностика. В библиотеке только системные зависимости iOS.

## Проверено

- Локальная сборка и Mach-O ARM64/iOS, хеши страниц подписи.
- Unit-тесты с UBSan и protobuf parity с Google Protobuf.
- Наличие требуемых методов в основном бинарнике YouTube 21.40.5.
- Упаковка IPA, сохранение прежних зависимостей, ZIP CRC.
- Готовая MP3-дорожка для контрольного прямого MP4 через сервис VOT.

## Не подтверждено

Патч не запускался на iPhone. Полный сценарий перевода YouTube внутри приложения,
интерфейс, точность звука, чистая IPA, совместимость модов, PiP и фон не проверены.
Живой тест ссылки YouTube завершился ошибкой сервиса после ожидания. Реальный
upload из нативного плеера ещё требует проверки. «Живые голоса» с авторизацией
не реализованы. Готовность контрольного MP3 не означает прохождения этих пунктов.
