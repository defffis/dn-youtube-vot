# 0.2.0-alpha — нативные настройки, управление и вход

Плавающая кнопка с версией удалена из основной библиотеки. Добавлены категория
VOT в настройках YouTube, значок в штатном ряду плеера, таймер ожидания,
автоматическое включение, зелёный активный значок и выключение/отмена нажатием.
Громкость/языки/смещение доступны в приложении и плеере; удержание значка
открывает панель. Адаптеры меню шестерёнки требуют проверки на устройстве.

Добавлены OAuth + PKCE через страницу Яндекса и ввод кода, ручной токен,
Keychain, выход и живые голоса; сервер direct/современный Worker/custom HTTPS.
OAuth не передаётся сторонним серверам. Пароли/токены в чат не нужны.

Подтверждены сборка -Werror, Mach-O/подписи, host-тесты состояний и protobuf
standard/lively. Контрольный прямой MP4 дал MP3. Пользовательский YouTube
xvFZjo5PgG0 дал status 6 (нужно исходное аудио). Worker checks вернули 405/503.
Полный перевод YouTube, новый native UI/OAuth/Keychain и живые голоса на iPhone
ещё не подтверждены. Пользовательские скриншоты доказывают загрузку только 0.1.1.

В GBox взять исходную рабочую IPA и внедрить только новую DNYouTubeVOT.dylib.
Удалить старую DNVOT/Probe из внедрения. Полная инструкция docs/UI_020.md.
Новая готовая IPA не включена. Устройство для собственного runtime-теста недоступно.
