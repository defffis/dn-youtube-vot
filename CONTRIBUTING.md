# Разработка

Перед изменениями прочитайте [STATUS.md](STATUS.md) и [ROADMAP.md](ROADMAP.md).
Наличие реализации отделяйте от статической проверки, живого запроса к сервису
и проверки на реальном iPhone.

1. Соберите `bash build.sh` в Linux со средой из `tools/setup_toolchain.py`.
2. Выполните `bash test.sh`. Для protobuf parity нужен protobuf==6.33.0.
3. Изменения протокола проверяйте по зафиксированным источникам и живым ответам.
4. Изменения адаптера сверяйте с сигнатурами целевой версии YouTube.
5. При исправлении синхронизации добавляйте воспроизводимый сценарий в тесты.
6. Результаты проверки на устройстве фиксируйте с версией iOS, YouTube, ссылкой
   на публичное видео и шагами воспроизведения.

Не коммитьте IPA, SDK, скомпилированные библиотеки, сертификаты, профили, токены,
cookies, секреты сессии или подписанные медиа-URL. Готовые сборки размещаются
в Releases закрытого репозитория. Сохраняйте уведомления лицензий исходных проектов.
